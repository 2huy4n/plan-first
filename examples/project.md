# 给内部后台加登录

## 目标

让内部员工使用现有账号登录后台，替换当前写死的测试入口。

## 用户与场景

内部员工每天进入后台处理订单；目前只能使用固定测试账号。

## 范围

- In: 登录页、会话、退出、路由守卫。
- Out: 注册、找回密码、第三方登录、角色权限、数据库迁移。

## 验收标准

- [ ] 正确账号可以进入 `/dashboard`
- [ ] 错误密码显示提示且不跳转
- [ ] 退出后回到登录页
- [ ] 现有测试命令通过

## 约束与假设

- 使用现有账号表，不改表结构。
- 兼容当前 Node.js 18+ 环境。
- 交付形式：production。
